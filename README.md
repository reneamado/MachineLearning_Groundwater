# MachineLearning_Groundwater

Este repositorio contiene el código en Python desarrollado como parte de la tesis de maestría en Hidrogeología Ambiental, titulada:

**“Modelado con técnicas de aprendizaje automático (machine learning) para la gestión del agua subterránea a escala regional - Estudio de caso: Sector norte del Valle Medio del Magdalena”.**

## Descripción del Proyecto

Este estudio aplica métodos de aprendizaje automático supervisado para analizar y predecir la disponibilidad de agua subterránea a nivel regional. Se desarrollaron múltiples modelos con el fin de identificar patrones en variables hidrogeológicas, geográficas y ambientales.

### Métodos empleados:
- Regresión Logística (RL)
- Bosque Aleatorio (BA)
- LightGBM
- Redes Neuronales Artificiales (RNA)
- Máquina de Vectores de Soporte (SVM)

### Detalles del modelo:
- **Número total de modelos construidos:** 19  
- **Métricas de evaluación:** Precisión, Sensibilidad, Puntaje F1  
- **Mejores desempeños:** RNA y SVM

## Requisitos

- El procesamiento está optimizado para ejecutarse en la plataforma **Google Colaboratory (Colab)**.
- El entorno base es **Python 3**.
- Cada cuaderno de Jupyter incluye una sección inicial con la instalación y carga de las librerías necesarias.
